## 🚀 Giới thiệu bài làm
Bài thực hành số 1 môn Lập trình Web xây dựng một ứng dụng Blog hoàn chỉnh sử dụng **Next.js (App Router)** và **Tailwind CSS**.

### Các tính năng chính đã hoàn thành:
1. **Quản lý mã nguồn với Git:** Khởi tạo repository công khai (Public Repo) trên GitHub, thực hiện commit và push code theo đúng quy trình[cite: 2].
2. **Cấu trúc dự án Next.js:** Sử dụng Next.js App Router, chia tách mã nguồn thành các thư mục và component tái sử dụng (`Header`, `Badge`, `BlogCard`)[cite: 2].
3. **Giao diện Responsive:** Sử dụng **Tailwind CSS** để thiết kế giao diện linh hoạt, tương thích tốt trên các thiết bị từ Mobile, Tablet đến Desktop[cite: 2].
4. **Fetch dữ liệu từ REST API:** 
   * Lấy danh sách bài viết trực tiếp từ API `JSONPlaceholder` hiển thị lên trang danh sách[cite: 2].
   * Xây dựng trang chi tiết bài viết động (`/blog/[id]`) sử dụng Dynamic Route và xử lý Promise (`params`) theo chuẩn Next.js mới[cite: 2].
